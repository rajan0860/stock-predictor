# Contributing to Stock Predictor

Thank you for your interest in contributing! This is an early-stage research and learning project, and contributions are welcome.

## How to Contribute

1. **Check the Roadmap:** Look at the `README.md` to see what is currently planned or in progress.
2. **Open an Issue:** Before writing significant code, please open an issue to discuss your proposed changes or feature additions.
3. **Fork and Clone:** Fork the repository, create a branch for your feature, and submit a Pull Request.

## Development Guidelines

- **Code Style:** We aim to keep the code simple and readable. Please format your code cleanly.
- **Dependencies:** If adding a new dependency, please mention it in your PR. Keep dependencies minimal.
- **Documentation:** Update relevant documentation in `docs/` or `README.md` if your change affects usage or architecture.

## Setting up for Development

See the Quick Start guide in `README.md` for local setup instructions.

Thanks for helping improve the project!
